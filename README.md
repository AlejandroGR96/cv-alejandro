# CV Interactivo

## Estructura

```text
cv-interactivo/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── img/
    └── perfil.svg
```

## Cómo usarlo

1. Abre `index.html` en VS Code.
2. Reemplaza los textos de ejemplo por tus datos reales.
3. Sustituye `img/perfil.svg` por tu foto (puedes llamarla `perfil.jpg` y cambiar el `src` del HTML).
4. Cambia los enlaces de GitHub, LinkedIn e Instagram.
5. Abre `index.html` en el navegador.

## Funciones incluidas

- Diseño responsive para computador, tablet y celular.
- Modo oscuro/claro guardado en `localStorage`.
- Barra de progreso de lectura.
- Animaciones al hacer scroll.
- Texto animado en el encabezado.
- Filtros interactivos de proyectos.
- Menú móvil.
- Tarjetas, timeline, habilidades y sección de contacto.
